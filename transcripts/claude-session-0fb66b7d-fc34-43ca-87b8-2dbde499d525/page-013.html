Judge 4: Format

This judge evaluates whether the response follows the <format> rules in the system prompt. Four rubrics, all binary:

R1 — prose_opens The response opens with a key insight or framing sentence in prose. Fails if the first substantive content is a list, a header, or a bare fact without framing.

R2 — lists_used_appropriately If lists appear, they enumerate genuinely parallel, discrete items with no narrative relationship (e.g., step sequences). Fails if lists are used to organize an explanation that should be prose.

R3 — list_style_consistent If the response contains any lists, exactly one format (dashes or numbers) is used throughout. Fails if both appear in the same response. Passes vacuously if there are no lists.

R4 — citation_correct - If the tool was called: the response ends with a Sources: line naming the Wikipedia article(s) used. - If the tool was not called: the response includes a brief note that the answer comes from general knowledge. - Fails if the citation pattern for the mode is absent or mismatched.

Pass/fail: R1 and R2 and R3 and R4

This judge takes as input: agent_response (str), tool_was_called (bool). The judge needs no external search — it only reasons about the structure and citation of the response itself.
