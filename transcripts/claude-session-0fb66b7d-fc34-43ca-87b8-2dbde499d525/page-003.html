Good question to pin down. Two options:

  • API endpoints — FastAPI exposes GET /api/traces (list of sessions with metadata) and GET /api/traces/{session_id} (full session JSON). The traces/ directory stays internal; the frontend only talks to the API. Clean, and leaves room to add filtering/pagination later.

  • Static mount — FastAPI mounts the traces/ directory directly as static files. The frontend fetches /traces/<session_id>.json directly. Zero extra code, but the entire traces directory is publicly accessible and the frontend has to discover session IDs some other way.

I'd go with API endpoints — the list endpoint is necessary anyway (the frontend needs to know which sessions exist), and keeping traces/ internal is the right default given these files will contain full LLM request/response payloads.
